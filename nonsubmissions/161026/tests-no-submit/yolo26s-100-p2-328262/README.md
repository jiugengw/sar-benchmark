# YOLO26s 100-epoch P2

This package is prepared from YOLO26s-P2 training job 328262 and its supervised image-classification head. The head supplies image labels in `classification.csv`; detector-native classes supply box labels in `detection.json`. Predictions cover all 1,426 official course validation images.

The local holdout metrics will be saved beside the ZIP after training and evaluation finish. The official score is not known. The ZIP is for repository review and is not uploaded to the course leaderboard.
