# YOLO11s 100-epoch P2

This package uses the YOLO11s-P2 detector from Slurm job 328058 and its supervised image-classification head. The head supplies the image labels in `classification.csv`; detector-native classes supply box labels in `detection.json`. Predictions cover all 1,426 official course validation images.

Local holdout metrics from `results/yolo11s-100-p2-328058/seed_0/metrics.json`:

- Accuracy: 88.18%
- Macro-F1: 89.30%
- Detection mAP: 36.31%
- AP50: 63.14%

The holdout metrics are local model-selection results; the official score is not known. The ZIP is generated by `yolo11s_p2_package.sbatch` and is stored in this repository for review. It is not uploaded to the course leaderboard.
